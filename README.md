# UB CS 经

纽约州立大学布法罗分校（University at Buffalo）计算机科学本科选课与学习经验。

作者：**Ryuushonei**

这里记录在 UB 读 CS 的课程体验、教授风评、课程设计、作业与考试难点，希望能帮助后来的同学少踩一些坑。
